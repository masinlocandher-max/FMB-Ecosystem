## FMB News boundary

FMB News is intentionally not part of this repository. Its sole canonical application repository is `masinlocandher-max/FMBNews`.

All FMB News application code, editorial build output, Cloudflare Worker configuration, `/news*` routing, and legacy `/fmbnews*` routing belong to `masinlocandher-max/FMBNews`. Do not add or restore an FMB News application, newsroom build, `/news*` route, or `/fmbnews*` route in FMB-Ecosystem.

The original migration-source repositories listed above remain unchanged during validation unless a separate cleanup is explicitly performed.
