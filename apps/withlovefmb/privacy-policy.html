Privacy Policy

Clear, careful, and honest.

This policy distinguishes what Yoni keeps only in your browser from account and profile information that is handled remotely.

1. Who is responsible

With love, FMB and Yoni are operated by Francine Marie Bautista. Privacy questions and account requests may be sent to withlovefmb@gmail.com.

2. What Yoni processes today

  • Remote authentication data: existing-member sign-in uses Supabase Authentication. The authentication service handles the account identifier, email address, email-verification state, session information, and password-reset requests. Passwords are processed by the authentication provider and are not displayed to site administrators by Yoni.
  • Remote member profile data: after sign-in, Yoni reads the existing Supabase profiles record. The current Yoni interface uses the member name or display name when present, username, biography, avatar preset, and app theme. Yoni can update the username, biography, avatar preset, and app theme.
  • Local-only Yoni records: check-ins, journal entries, Yoni chat history, response-mode preference, reminder preference, theme cache, local profile cache, locally logged unrecognized questions, and any older Kind Wall preview queue are stored in this browser using local storage.
  • Kind Wall examples: the example stories shown in the current Kind Wall preview are built-in fictional samples. They are not member submissions.
  • General contact: if you voluntarily email With love, FMB, that message is handled by the email service you use and the receiving mailbox. It is separate from Yoni's local journal, check-in, chat, and Kind Wall preview storage.

3. What Yoni does not currently transmit

The current Yoni app does not send journal entries, check-ins, Yoni chat history, locally logged unrecognized questions, or Kind Wall preview text to a moderator queue or public community database. The current app does not publish Kind Wall posts and does not claim that local Yoni records are stored in a remote journal database.

4. Why information is used

Remote authentication information is used to sign existing members in, maintain an authenticated session, sign out, and send requested password-reset links. Remote profile information is used to personalize the signed-in profile and keep the supported profile fields consistent across authenticated access. Local browser records are used only to provide Yoni's on-device check-in, journal, chat, history, theme, reminder-preference, export, and delete features.

5. Local journals, check-ins, chat, and preferences

These records are saved in the browser on the device where Yoni is used. They are not uploaded by the current Yoni implementation. Signing out of the remote account does not by itself erase these local records. The Privacy and personal control screen can export local Yoni records and can delete check-ins, journals, or all local Yoni data from that browser.

Because browser storage remains on the device until it is deleted, cleared, or otherwise removed by the browser or device, avoid storing passwords, financial credentials, government identification numbers, full medical records, or information that would create serious harm if exposed.

6. Remote account and profile data

Yoni uses Supabase for existing-member authentication and the current member profile record. Authentication-session data may also be persisted in browser storage so the member can remain signed in. The current Yoni interface does not reopen registration and does not create a new account through the disabled registration form.

7. Kind Wall status

The Kind Wall is not a live public community feature today. The posting control is disabled. Nothing typed into the current preview is sent to a moderator, reviewed, approved, or published. Older preview drafts that may already exist in the browser remain local to that browser until the user clears local Yoni data or browser storage. The visible sample stories are fictional examples, not real member posts.

8. Service providers

The live website is hosted through Vercel. Supabase provides the current authentication service and member-profile data service used by Yoni. Browser local storage is used for the local-only Yoni records described above. These services operate under their own security and privacy terms. Yoni uses a publishable client credential for browser access and does not place a Supabase service-role secret in the public browser configuration.

9. Retention

Local Yoni records remain in that browser until the user deletes them, clears browser storage, the browser removes them, or the device is reset. Remote authentication and profile records may remain while the existing account remains active and may be subject to provider, security, legal, or backup requirements. There is currently no Yoni database of pending or published Kind Wall posts to retain.

10. Security

Yoni uses authenticated access for existing member accounts and relies on the configured Supabase project for remote account and profile access controls. Local Yoni records are protected primarily by control of the browser and device on which they are stored. This policy does not claim that local journals, chats, check-ins, or Kind Wall preview text are remotely encrypted, reviewed, or protected by server-side journal database permissions because the current app does not send those records to such a database.

No online or local-storage system can promise absolute security. Suspected unauthorized account access or a possible privacy incident should be reported promptly to the contact email.

11. Your choices and controls

  • Use Yoni's export control to create a JSON copy of the local check-ins, journals, chat, local profile cache, older Kind Wall preview queue, theme, reminder preference, response mode, and locally logged unrecognized questions stored in that browser.
  • Delete local check-in history or local journal entries from the Privacy and personal control screen.
  • Use “Delete all local Yoni data” to remove Yoni's current local-storage records from that browser.
  • Update supported profile fields such as username, biography, fruit avatar preset, and theme while signed in.
  • Request a password-reset email for the remote authentication account.
  • Ask about access, correction, or deletion of available remote account/profile information by contacting the privacy address.

See the Data Rights page for the current request process.

12. Children and sensitive information

Registration is currently closed. Yoni is not designed to collect highly sensitive records through its journal or Kind Wall preview. Do not use Yoni to store passwords, one-time codes, financial credentials, government identification numbers, or full medical records.

13. Emergency support

Yoni is a digital companion, not an emergency, medical, psychological, legal, or crisis-response service. Local journals, chat, check-ins, and the Kind Wall preview are not monitored as emergency channels. For immediate danger or crisis support, use Yoni's Human Help screen or contact appropriate emergency services.

14. Changes to this policy

Material changes will be dated and presented clearly. Any future community publishing, moderation, remote journal storage, or other new data flow must be reflected here before it is described to users as active.

15. Questions

Email withlovefmb@gmail.com with the subject “Privacy Request.” Registration remains closed. This operational policy should still be reviewed by a qualified Philippine privacy professional before any future expansion of registration, public community posting, or additional remote data processing.
